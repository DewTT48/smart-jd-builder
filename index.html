FROM INPUT TO USABLE JD

JD ที่เป็นมาตรฐาน เริ่มจาก Workflow ที่เป็นระบบ

ลดการเริ่มใหม่จากเอกสารเก่าและข้อมูลกระจัดกระจาย พร้อมรักษาบริบทขององค์กรไว้ในทุกตำแหน่ง

01

Structured from the start

เก็บข้อมูลตำแหน่งด้วยโครงสร้างเดียวกัน รองรับทั้งการกรอกทีละตำแหน่งและ Batch Import

02

Built for your context

ใช้ Business Context, Core Competency และ Managerial Competency ขององค์กรประกอบการสร้างร่าง

03

AI-assisted, human-reviewed

AI ช่วยสร้างเป็นรายส่วน ขณะที่ผู้ใช้ยังเลือก ตรวจ แก้ไข และยืนยันสิ่งที่จะนำไปใช้จริง

04

Ready to review and reuse

แก้ไขในรูปแบบตาราง ดู Document Preview และสร้าง Google Docs ที่ยังปรับปรุงต่อได้

MORE THAN AI TEXT

ไม่ใช่แค่ให้ AI เขียนข้อความ

JD Builder ออกแบบมาเพื่อจัดกระบวนการทำ JD ตั้งแต่ข้อมูลต้นทาง ไปจนถึงเอกสารที่ทีม HR ตรวจสอบและนำไปใช้ต่อได้จริง

AI ทั่วไป Prompt → ข้อความ

ได้ร่างเร็ว แต่ผู้ใช้ต้องจัดโครงสร้าง บริบท และรูปแบบเอกสารต่อเอง

JD Builder Input → Context → AI → Review → Docs

ทุกขั้นเชื่อมต่อกัน และ HR ยังควบคุมเนื้อหาก่อนนำไปใช้งาน

ORGANIZATION COMPETENCY

กำหนดพฤติกรรมร่วมที่ต้องการจากทุกตำแหน่ง

เพิ่มเองหรือให้ AI ช่วยเสนอ Core Competency 1–6 ข้อ แล้วเลือกเฉพาะรายการที่จะใช้จริง

BATCH IMPORT

นำเข้าหลายตำแหน่งในจุดเดียว

ดาวน์โหลดเทมเพลต อัปโหลด XLSX, CSV หรือ TSV แล้วเลือกตำแหน่งที่จะเปิดใน Workspace

A CLEAR PROCESS

จากข้อมูลตำแหน่ง สู่เอกสารที่พร้อมใช้

ระบบช่วยจัดกระบวนการและสร้างร่าง โดยผู้ใช้ยังควบคุมเนื้อหาทุกขั้นตอน

  1. 1

    รับข้อมูลตำแหน่ง

    กรอกทีละตำแหน่งหรือนำเข้าจากเทมเพลตด้วยโครงสร้างเดียวกัน

  2. 2

    เชื่อม Business Context

    นำบริบทธุรกิจและ Competency ขององค์กรมาใช้ประกอบการสร้างร่าง

  3. 3

    AI ช่วยสร้างร่าง

    สร้างเนื้อหาตามหัวข้อมาตรฐาน และสร้างใหม่ได้เป็นรายส่วน

  4. 4

    Human review และส่งออก

    ผู้ใช้เลือก ตรวจ แก้ไข ดู Preview และสร้าง Google Docs ที่แก้ต่อได้

การใช้งาน AI อย่างรับผิดชอบ

AI ช่วยร่าง มนุษย์เป็นผู้ตรวจ แก้ไข และตัดสินใจ

AI ช่วยจัดโครงสร้างและเสนอเนื้อหาร่างจากข้อมูลที่ผู้ใช้ให้

ผู้ใช้เลือก ตรวจ แก้ไข และยืนยันก่อนสร้างเอกสารทุกครั้ง

ระบบไม่ตัดสินใจด้านการจ้างงาน ค่าตอบแทน การเลิกจ้าง หรือ Job Evaluation แทนผู้ใช้
